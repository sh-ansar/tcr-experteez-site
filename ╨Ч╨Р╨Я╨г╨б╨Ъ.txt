TCR Experteez Ltd — запуск сайта

БЫСТРЫЙ ЗАПУСК НА WINDOWS

1. Установите PHP 8 или новее и добавьте PHP в PATH.
2. Распакуйте архив.
3. Откройте папку сайта.
4. Запустите файл start.bat.
5. Сайт откроется по адресу: http://127.0.0.1:8000

Ручной запуск через PowerShell:

php -S 127.0.0.1:8000

После этого откройте в браузере:
http://127.0.0.1:8000

ЗАПУСК НА macOS / LINUX

Откройте Terminal в папке сайта и выполните:

chmod +x start.sh
./start.sh

Либо:

php -S 127.0.0.1:8000

РАЗМЕЩЕНИЕ НА ХОСТИНГЕ

1. Загрузите все файлы и папку assets в public_html.
2. Убедитесь, что включен PHP 8 или новее.
3. Проверьте поддержку функции PHP mail().
4. Заявки отправляются на info@tcrexperteez.com.
5. Проверьте форму с рабочего HTTPS-домена.

Важно: при открытии index.html двойным щелчком дизайн и анимации отображаются, но PHP-отправка формы работать не будет. Для полной проверки используйте start.bat, start.sh либо хостинг с PHP.


ШРИФТЫ
